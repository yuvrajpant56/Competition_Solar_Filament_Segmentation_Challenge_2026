## 2. Competition Understanding

The competition uses the MAGFiLO solar-filament annotation dataset.

The task is to identify and segment individual solar filaments from full-disk H-alpha solar observations.

Important characteristics:

- Original image resolution: 2048 × 2048 pixels.
- Image format: 8-bit JPEG.
- Images contain grayscale H-alpha observations.
- Ground-truth annotations are stored in COCO-style JSON.
- Some physical images are independently annotated by multiple human experts.
- Each image can contain multiple individual filaments.
- Filaments may include thin, faint, thread-like structures.
- The background contains noise, imaging artifacts, and dark solar structures resembling filaments.

The primary competition leaderboard metric is **Panoptic Quality (PQ)**.

PQ considers both segmentation quality and correct recognition of individual filament instances. False positives, missed filaments, fragmentation, and incorrectly merged filament instances can reduce performance.

The organizers also evaluate the quality of the predicted morphology, documentation, and implementation.

Read the competition documentation and official self-evaluation notebook before implementing evaluation:

https://www.kaggle.com/code/azimahmadzadeh/self-evaluation-notebook

Do not approximate the competition metric when the official implementation is available.

Do not train on hidden test annotations or use external ground-truth metadata prohibited by the competition rules. In particular, do not use publicly available MAGFiLO annotations that may reveal the competition's test labels.

## 3. Main Research Objective: Curriculum Learning

I want to investigate whether curriculum learning improves solar filament instance segmentation.

My initial hypothesis is:

**Training an instance-segmentation model on images with fewer annotated filaments before progressively introducing images with more filaments will improve generalization and Panoptic Quality compared with conventional random training.**

The proposed curriculum divides training images into:

1. Easy images: relatively few annotated filaments.
2. Medium images: moderate numbers of annotated filaments.
3. Hard images: relatively many annotated filaments.

The primary proposed schedule is:

- Stage 1: Train on Easy + Medium images.
- Stage 2: Continue training on Easy + Medium + Hard images.

I specifically want to determine whether this training order produces a measurable improvement, rather than merely benefiting from reduced data diversity during initial training.

**Keep the model architecture, training budget, validation data, and hyperparameters consistent across controlled experiments. Curriculum scheduling must be the main experimental variable.**

Treat annotation count as a proposed proxy for difficulty, not an established fact. Investigate whether it actually correlates with segmentation difficulty.

# PHASE B: Data Preparation

Avoid training/validation leakage.

If multiple annotators labeled the same image, do not incorrectly combine their polygons as if they represented different physical filaments.

- Use one deterministic representative annotation set per physical image.
- Prefer a representative set selected by agreement with the other annotators where possible.

# PHASE E: Controlled Curriculum Experiments

## 13. Experimental Design

Implement the following experiments using YOLO11m-seg.

| Experiment | Initial training | Later training | Purpose |
|---|---|---|---|
| E1 | All images | All images | Standard baseline |
| E2 | Random subset matching the size of Easy + Medium | All images | Random subset control |
| E3 | Easy + Medium | All images | Proposed curriculum |
| E4 | Medium + Hard | All images | Reverse-difficulty control |
| E5 | Easy → Easy + Medium → All | Three-stage schedule | Gradual curriculum |

### E1: Standard baseline

Train using all training images with standard random sampling throughout the full training budget.

### E2: Random curriculum control

For the first 30% of optimizer updates, sample from a fixed random subset containing approximately the same number of physical images as the Easy + Medium subset.

For the remaining 70%, sample uniformly from all training images.

This experiment tests whether any improvement is merely caused by initially training on fewer unique images.

### E3: Proposed curriculum

This is the primary experiment.

Stage 1 — 30% of total optimizer updates:

Train using Easy + Medium images.

Stage 2 — 70% of total optimizer updates:

Continue training using Easy + Medium + Hard images.

Do not reset model weights between stages.

Maintain the same overall learning-rate schedule as the standard baseline.

### E4: Reverse curriculum

Stage 1 — 30% of updates:

Train using Medium + Hard images.

Stage 2 — 70% of updates:

Train using all images.

This helps determine whether the proposed difficulty order matters.

### E5: Three-stage curriculum

Stage 1 — 20% of updates:

Easy images only.

Stage 2 — 20% of updates:

Easy + Medium images.

Stage 3 — 60% of updates:

All images.

Continue from the previous stage's model weights without resetting.

### Critical fairness requirements

Use the same:

- Initial pretrained model weights
- Data split
- Total number of optimizer updates
- Batch size
- Optimizer
- Learning-rate schedule
- Augmentations
- Loss functions
- Evaluation procedure
- Inference configuration
- Post-processing method

Express stage durations in **optimizer updates**, not ordinary epochs, because each curriculum stage uses a different-sized image pool.

Use sampling with replacement where necessary to maintain equal update budgets.

Keep random seeds recorded and pair seeds across experiments.

Track which images are presented during each stage and summarize sampling exposure by difficulty group.

Validate on the complete validation set throughout training, not only on the groups currently being trained.

# PHASE H: Statistical Analysis

## 18. Determine Whether the Curriculum Actually Helps

The primary comparison is:

\[
\Delta PQ = PQ(E3) - PQ(E1)
\]

Also compare:

\[
PQ(E3) - PQ(E2)
\]

The E2 comparison is crucial because it distinguishes the proposed difficulty ordering from generic subset-based warm-up.

For repeated experiments:

- Report mean PQ and standard deviation.
- Report paired performance differences.
- Calculate confidence intervals where feasible.
- Use resampling grouped by independent physical observations or observation dates, not individual annotator records treated as independent samples.

Do not claim curriculum learning is beneficial unless results consistently support that conclusion.

If curriculum learning does not improve performance, investigate why and report the negative result honestly.

Possible explanations include:

- Filament count is not a reliable difficulty measure.
- Easy images contain too few positive examples.
- Early training biases the detector toward background.
- The later training stage is insufficient.
- Different annotators introduce label uncertainty.
- The model already learns effectively through random sampling.
